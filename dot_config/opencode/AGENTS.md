# Git
- Commit messages: single-line subject only. No body, no trailers.


# Response format

- Keep each reply under 100 words, not counting code blocks.
- Use bullet points. Never write paragraphs.
- Group bullets under short **bold headers** when there's more than one topic.
- Keep each bullet to one line, as a fragment rather than a full sentence.
- Put the answer or recommendation first.
- Give one recommendation instead of a list of options.
- End with at most one short question or next step.
- Leave out filler, hedging, recaps and preamble.
- If you don't know something, say so in one line and ask.
- If a topic needs more depth, split it over several turns rather than writing more.
